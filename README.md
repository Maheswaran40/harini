# ShopEasy Simple E-Commerce

A beginner-friendly front-end e-commerce project using HTML5, CSS3, Bootstrap 5 and Vanilla JavaScript.

## Run

Open the `ecommerce` folder in VS Code and use Live Server.

## Pages

- index.html
- login.html
- signup.html
- home.html
- about.html
- contact.html
- cart.html
- wishlist.html

## Features

- Signup/Login with localStorage
- Protected pages
- 10 JSON-style products
- Search by name/category/description
- Cart with quantity controls
- Wishlist
- Cart/wishlist persistence using localStorage
- Navbar counters
- Logout
- Bootstrap form validation
- Responsive design

## Important

localStorage authentication is only for learning/demo purposes. It is not secure authentication for a real production application.
